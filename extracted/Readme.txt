Takatis - A Tribute To Manfred Trenz (Patch)

Dieser Patch erweitert die Version 1.1 auf Version 1.2



Verwendung des Patches:
-----------------------


Die Datei "Takatis.exe" in das Takatis-Installationsverzeichnis kopieren (alte Datei überschreiben).
Die Datei "FAQ.html" in das Takatis-Installationsverzeichnis kopieren (alte Datei überschreiben).
Die Datei "hud-unten.gfx" in das Verzeichnis "gfx" kopieren (alte Datei überschreiben).
Die Datei "player-energy.gfx" in das Verzeichnis "gfx" kopieren.



Neu in der Version 1.2:
-----------------------


- Auf einigen Computern waren die 3D-Endgegner nicht sichtbar und man konnte sie demnach nicht besiegen. Dieser Fehler ist nun behoben.

- Auf einigen Computern konnte Takatis überhaupt nicht gestartet werden. Das Logfile wies darauf hin, das einige Grafiken nicht erzeugt werden konnten. Dies sollte nun behoben sein. Da dieser Fehler bei uns nicht auftrat, bitten wir um Rückmeldung ob dieses Problem noch immer besteht.

- Vielen war der Schwierigkeitsgrad zu hoch. Nun hat der Spieler drei Energiebalken. Wird der Gleiter von einem gegnerischen Schuss getroffen, so wird ein Balken abgezogen. Bei Kollision mit einem Gegner verliert man zwei Balken.

- Einige Joypads wurden nicht erkannt. Dieses Problem sollte nun gelöst sein.


Bekannte Bugs:
--------------


- Das Spiel läuft nicht auf jedem System ruckelfrei. Wie man dieses Problem vorläufig behebt, kann in der FAQ nachgelesen werden.
