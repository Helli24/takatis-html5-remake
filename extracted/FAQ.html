FAQ

 

Hier werden die am meist gestellten Fragen zu Takatis beantwortet. Ein Update der FAQ könnt ihr auf unserer Homepage (www.poke53280.de.vu) herunterladen.

 

F: Takatis ruckelt bei mir, läuft zu schnell oder zu langsam, was kann ich tun?

A: Takatis lief auf allen getesteten Rechnern ruckelfrei, jedoch mit zwei Ausnahmen: Zum einen gab es Probleme mit WindowsME und Windows2000. Deshalb können wir für einen problemlosen Ablauf von Takatis nur auf Windows98 ausgehen. Jedoch gab es auch mit Windows98 auf einem Rechner das Problem, das Takatis ruckelte. Dies wurde auf Folgende Weise behoben:

- In die Systemsteuerung gehen, dort auf "Anzeige" und dann auf den Reiter "Einstellungen".
- Dort die Bildschirmauflösung auf "640x480" und die Farbtiefe auf "16 Bit" stellen
- Nun auf den Button "Weitere Optionen" klicken und den Reiter "Grafikkarte" auswählen.
- Mit dem Menüpunkt "Bildwiederholfrequenz" eine Frequenz von 75hz einstellen.
- Die Änderungen übernehmen, dann wieder auf die vorige Einstellung wechseln.

Nun ist für die Auflösung "640x480x16" eine Bildwiederholfrequenz von 75hz eingestellt, ungeachtet von der aktuellen Einstellung. Dadurch arbeitet die Framebremse von Takatis optimal und das Ruckeln sollte verschwunden sein

F: Ich sehe überall hässliche grüne Ränder...woher kommt das und wie kann ich das beheben?

A: Dieser Fehler ist bisher nur ein einziges Mal aufgetaucht. Auf dem verwendeten System war eine "3Dfx Voodoo5 5500 (x3dfx-Treiber)" Grafikkarte installiert. Das Problem lässt sich beheben indem man den 2ten VSA100 Chip deaktiviert.
